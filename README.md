# CS-Ganerator

## Project Introduction
In this project, a framework called **CS-Ganerator** is proposed, which investigates the automatic generation of color schemes for web interface design by integrating both knowledge and data. Initially, an improved K-Means clustering algorithm is used to extract color scheme instances from a large image dataset with diverse themes. Subsequently, a Conditional Generative Adversarial Network (CGAN) augmented with knowledge modules is employed to discern the underlying color and thematic relationships under aesthetic principles, enabling the generation of thematic color schemes.

## Directory Structure

### 1-Color Extraction.py
Image Color Scheme Extraction Program

### 2-Color Scheme Dataset
- **training-data.xlsx**: The dataset used for actual model training, including 46,500 schemes.
- **template_data.xlsx**: The selected template library data.
- **template imgs**: Folder containing images of the color schemes from the template library.

### 3-Model
- **CGAN_CUDA_model_d_g.ipynb**: The model program.
- **generator_model.pt**: Pre-trained model parameters.
- **process_imgs**: Stores test output images from the training process.

### 4-html_tool
The source code for the front-end interactive tool mentioned in the experimental section 4.5. Download this folder and open the **page_hex_en.html** file to experience it.

> **Note**: Because here, the tool only plays the role of interaction and display of color schemes, the back-end has not been developed to connect with the model. Instead, a large number of schemes are pre-generated by the model as the built-in data, which can be retrieved and fed back according to user needs.

### 5-Complete image results of the experiment
Complete image result data from the experiment, corresponding to Figures 7 and 8 in the paper.

## Theme Tag Correspondence
To better describe the themes, the theme tags on the "html_tool" page are different from the brief tags in the training dataset. The corresponding relationships are as follows:

- cate-food → food
- starry sky → stars
- illustration → pixiv
- oil painting → oil
- film → CNU
- solemnity → dangjian
